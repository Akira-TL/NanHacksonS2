# 垃圾电/热能回收管理平台 UI/UX 设计规范

> 文档版本：v1.0
> 日期：2026-05-01
> 设计风格：Material Design（工业监控版）
> 目标用户：调度操作员、运维工程师、数据分析师、评委/观众

---

## 1. 设计理念与视觉规范

### 1.1 设计定位

本平台是**工业级监控管理系统**，核心诉求是：
- **信息密度高**：同时展示大量实时数据
- **状态一目了然**：设备/系统当前状态一眼可辨
- **操作零失误**：关键操作有充分确认与防错机制
- **大屏友好**：支持大屏展示模式，评委/观众观摩

### 1.2 色彩系统

| 角色 | 色值 | 用途 |
|-----|------|------|
| Primary | #1976D2 | 主导航、按钮、重要标题 |
| Primary Dark | #0D47A1 | 状态栏、深色背景 |
| Secondary | #00ACC1 | 辅助操作、次要信息 |
| Background | #121212 | 深色模式背景 |
| Surface | #1E1E1E | 卡片、面板背景 |
| Surface Elevated | #2D2D2D | 浮层、弹窗背景 |
| Text Primary | #FFFFFF | 主要文字 |
| Text Secondary | #B0BEC5 | 次要文字 |
| Success | #4CAF50 | 正常状态、达标 |
| Warning | #FF9800 | 警告状态、接近阈值 |
| Error | #F44336 | 错误状态、超限 |
| Heat High | #FF5722 | 高温指示 |
| Heat Low | #2196F3 | 低温指示 |

### 1.3 字体规范

| 元素 | 字体 | 字号 | 字重 |
|-----|------|-----|------|
| H1 大标题 | Roboto | 32px | 500 |
| H2 页面标题 | Roboto | 24px | 500 |
| H3 卡片标题 | Roboto | 18px | 500 |
| Body 正文 | Roboto | 14px | 400 |
| Caption 辅助 | Roboto | 12px | 400 |
| Data Large 大数字 | Roboto Mono | 48px | 300 |
| Data Medium | Roboto Mono | 24px | 400 |
| Data Small | Roboto Mono | 14px | 400 |

### 1.4 间距系统

基础单位：**8px**

| 名称 | 间距 | 用途 |
|-----|------|------|
| xs | 4px | 紧凑元素间距 |
| sm | 8px | 小组件内部间距 |
| md | 16px | 卡片内边距 |
| lg | 24px | 区块间距 |
| xl | 32px | 页面边距 |
| xxl | 48px | 大区块分隔 |

### 1.5 圆角与阴影

| 元素 | 圆角 | 阴影 |
|-----|------|------|
| 按钮 | 4px | 无 |
| 卡片 | 8px | elevation 2 (0 2px 4px rgba(0,0,0,0.2)) |
| 弹窗 | 12px | elevation 8 (0 8px 16px rgba(0,0,0,0.4)) |
| 芯片/标签 | 16px | 无 |

### 1.6 组件状态

| 状态 | 视觉表现 |
|-----|---------|
| Default | 正常颜色 |
| Hover | 背景色变浅10% |
| Active/Pressed | 背景色变浅20% + ripple效果 |
| Disabled | opacity 0.38 |
| Loading | 显示spinner，禁用交互 |
| Selected | Primary色边框/背景 |

## 8. 大屏展示模式

### 8.1 设计特点

专为评委/观众设计的大屏展示模式，特点：
- **超大字体**：数据文字至少32px起
- **高对比度**：纯深色背景+亮色数据
- **简化导航**：隐藏侧边栏，全屏展示
- **自动轮播**：关键指标自动轮播展示

## 10. 交互规范

### 10.1 动画规范

| 动效类型 | 时长 | 缓动函数 | 用途 |
|---------|------|---------|------|
| Ripple | 300ms | ease-out | 按钮点击反馈 |
| Fade | 200ms | ease-in-out | 显示/隐藏 |
| Slide | 250ms | ease-out | 面板展开 |
| Expand | 200ms | ease-out | 卡片展开 |
| Number Roll | 500ms | ease-out | 数字变化 |

### 10.2 数据刷新方式

| 刷新类型 | 频率 | 视觉反馈 |
|---------|------|---------|
| 实时数据 | 5-10秒 | 数值渐变更新，无闪烁 |
| 告警 | 即时 | 新告警顶部闪烁+声音 |
| 状态变化 | 即时 | 状态颜色过渡300ms |

### 10.3 操作确认

| 操作类型 | 确认方式 |
|---------|---------|
| 紧急停机 | 二次确认 + 密码验证 |
| 模式切换 | 确认弹窗 + 5秒倒计时取消 |
| 参数调整 | 直接生效 + 操作记录 |
| 批量操作 | 确认弹窗列出受影响设备 |
