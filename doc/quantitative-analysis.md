### 2.3 热量回收计算公式

**压缩机式回收量：**
```
Q_compressor = P_compressor × COP × t × η_storage

其中：
- P_compressor = 压缩机功率(kW)
- COP = 性能系数(典型值3.2)
- t = 运行时间(h)
- η_storage = 存储效率(92%)
```

**发热片回收量：**
```
Q_heat_sheet = Σ(A_i × η_i × (T_battery - T_ambient) × t_i)

其中：
- A_i = 第i个发热片面积(m²)
- η_i = 第i个发热片效率
- T_battery = 电池温度(°C)
- T_ambient = 环境温度(°C)
```

**风冷+压缩协同回收量：**
```
Q_forced_air = Q_removed × η_fan × COP_effective

其中：
- Q_removed = 风冷带走的热量(kW)
- η_fan = 风机效率(约75%)
- COP_effective = 压缩机有效系数(约2.8)
```

## 四、电池寿命损耗分析

### 4.1 温度对电池寿命的影响

电池寿命与温度强相关，本系统通过精准温控显著延长电池寿命。

| 温度区间 | 相对寿命 | 日均容量衰减 | 说明 |
|---------|---------|-------------|------|
| < 0°C | 40% | 0.8%/天 | 严重负面影响 |
| 0-10°C | 65% | 0.4%/天 | 较大负面影响 |
| **15-25°C** | **100%** | **0.1%/天** | **最佳工作区间** |
| 25-35°C | 85% | 0.2%/天 | 轻微负面影响 |
| 35-45°C | 55% | 0.5%/天 | 较大负面影响 |
| > 45°C | 30% | 1.2%/天 | 严重负面影响 |

### 4.3 电池健康度(SOH)预测模型

```
SOH(t) = SOH₀ × e^(-λ × t)

其中：
- SOH₀ = 初始健康度(100%)
- λ = 衰减系数，与温度相关
  - λ = 0.004 (15-25°C最佳区间)
  - λ = 0.015 (0-10°C区间)
  - λ = 0.035 (>35°C区间)
- t = 运行天数
```

      0    0.5    1.0    1.5    2.0    2.5    3.0

### 4.4 温度波动对寿命的影响

除了绝对温度，温度波动也是影响寿命的重要因素。

| 场景 | 温度波动范围 | 等效寿命损耗 |
