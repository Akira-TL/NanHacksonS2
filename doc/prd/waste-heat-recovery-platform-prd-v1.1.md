## 1. 背景与问题定义

### 1.1 业务背景

戈壁地区拥有丰富的风电资源，但风电具有**间歇性和波动性**特点，大量"垃圾电"（弃风电力）未被有效利用。同时，戈壁地区昼夜温差极大（夏季白天可达50°C，夜间降至-10°C），电池库温度管理面临严峻挑战。

**核心矛盾**：

- 夜间低温导致电池效率急剧下降（0°C以下容量衰减可达40%）
- 弃风电力无法消纳，造成能源浪费
- 传统电加热方式能耗高、成本大

### 1.2 解决方案

构建**垃圾电/热能回收管理平台**，以硅基熔融堆为核心热源，结合电池库温控需求，实现：

- **热能存储与调度**：将弃风电力转化为热能存储，夜间释放供暖
- **多源协同优化**：整合风电、热泵、硅基单元、电池储能等多能源
- **智能温控策略**：参考特斯拉热泵系统多模式切换思想，实现±2°C精度的电池库温控

## 3. 用户模型与场景

### 3.1 用户角色

| 角色    | 职责        | 权限范围      |
| ----- | --------- | --------- |
| 系统管理员 | 系统配置、用户管理 | 全功能       |
| 调度操作员 | 实时监控、策略下发 | 监控+操作，无配置 |
| 运维工程师 | 设备巡检、故障处理 | 监控+告警处理   |
| 数据分析师 | 数据分析、报表查看 | 只读        |
| 展示观众  | 观摩演示      | 大屏展示模式    |

### 3.2 核心场景

**场景1：夜间电池库保温**

- 触发条件：环境温度<5°C，电池温度<15°C
- 执行策略：启用硅基单元供暖模式+热泵辅助
- 目标：维持电池温度在15-25°C

**场景2：弃风电力消纳**

- 触发条件：风电发电量>负荷需求，且电池已充满
- 执行策略：切换硅基单元至发电模式，将电能转化为热能存储
- 目标：最大化垃圾电消纳率

**场景3：熔融堆热量反向供暖**

- 触发条件：夜间电价低谷 + 环境温度<0°C + 电池温度<10°C
- 执行策略：熔融堆释放存储热能，向电池库供暖
- 目标：降低加热用电成本

## 4. 核心状态机

### 4.1 硅基单元工作模式状态机

```
                    ┌─────────────────┐
                    │    待机模式      │
                    │   STANDBY       │
                    └────────┬────────┘
                             │ 检测到弃风电力或供暖请求
                             ▼
              ┌──────────────────────────────┐
              │                               │
    ┌─────────▼─────────┐      ┌──────────────▼──────────┐
    │    发电模式        │      │      供暖模式            │
    │  POWER_GEN        │      │   HEATING               │
    └─────────┬─────────┘      └──────────────┬──────────┘
              │                                │
              │ 热能存储已满                    │ 供暖需求结束
              │ 或电力需求上升                  │ 或温度达标
              ▼                                ▼
```

| 状态         | 进入条件          | 退出条件       | 持续动作    |
| ---------- | ------------- | ---------- | ------- |
| STANDBY    | 初始/无信号        | 检测到弃风或供暖请求 | 低功耗监测   |
| POWER\_GEN | 弃风电力存在 + 电池满充 | 热能存储满或电力需求 | 硅基片发电产热 |
| HEATING    | 供暖请求 + 有热能存储  | 温度达标或存储耗尽  | 释放热能供暖  |

### 4.2 熔融堆热量管理状态机

```
         ┌──────────────────────────────────────────────────┐
         │                                                  │
         ▼                                                  │
   ┌──────────┐        热量收集中       ┌─────────────────┐ │
   │ 蓄热中   │ ◄──────────────────── │ 熔融堆控制样机   │ │
   │CHARGING  │      (白天/弃风)       │ (硅基单元)       │ │
   └────┬─────┘                       └────────┬────────┘ │
        │                                      │           │
        │ 热能存储达到上限                      │ 热量释放   │
        │ 或环境温度<5°C                        │           │
        ▼                                      ▼           │
   ┌──────────┐        热量释放中       ┌─────────────────┐ │
   │ 平衡态   │ ─────────────────────►  │ 放热中          │ │
   │BALANCED  │      (夜间/寒冷)        │ DISCHARGING     │ │
   └──────────┘                         └─────────────────┘ │
         │                                      │           │
         │ 存储热量耗尽                          │ 存储热量充足│
         │                                      │           │
         └──────────────────────────────────────┘
```

| 状态          | 触发条件            | 退出条件        | 关键动作     |
| ----------- | --------------- | ----------- | -------- |
| CHARGING    | 弃风电力存在 + 热量存储未满 | 存储满或停止信号    | 收集热量至熔融堆 |
| BALANCED    | 存储满或温度平衡        | 温度差>5°C触发切换 | 维持热平衡    |
| DISCHARGING | 环境<5°C或电池需要热量   | 存储耗尽或温度达标   | 释放热量至电池库 |

### 5.4 热量收集方式

系统支持三种互补的热量收集方式，针对不同场景和设备特性进行协同工作。

#### 5.4.1 压缩机式热量转移

| 属性   | 说明                        |
| ---- | ------------------------- |
| 原理   | 利用压缩机做功，将低温端热量转移至高温端盐融堆存储 |
| 适用场景 | 电池充放电产生的余热回收、环境温度5-25°C区间 |
| 效率   | 典型COP 2.5-4.0             |
| 控制方式 | 压缩机转速调节（0-100%）           |

**状态机：**

```
                    ┌─────────────────┐
                    │    待机         │
                    │   OFF          │
                    └────────┬────────┘
                             │ 检测到电池余热 + 盐融堆未满
                             ▼
              ┌──────────────────────────────┐
              │        热量收集中              │
              │      COMPRESSING             │
              │   热量→盐融堆                 │
              └──────────────┬───────────────┘
                             │ 热量已存储满 或 电池停止工作
                             ▼
                    ┌─────────────────┐
                    │    完成         │
                    │   COMPLETE     │
                    └─────────────────┘
```

| 状态          | 进入条件      | 退出条件       | 关键参数      |
| ----------- | --------- | ---------- | --------- |
| OFF         | 初始/无热量可收  | 电池工作+有存储空间 | 待机功耗<50W  |
| COMPRESSING | 电池放电+存储未满 | 存储满或电池停机   | 压缩机功率、COP |
| COMPLETE    | 存储已满      | 存储空间释放     | 记录收热量     |

**数据模型：**

```json
{
  "device_id": "compressor_unit_001",
  "state": "COMPRESSING",
  "compressor_speed_percent": 75,
  "cop": 3.2,
  "heat_collected_kwh": 125.5,
  "storage_level_percent": 45.2,
  "power_consumed_kw": 15.8,
  "inlet_temp_c": 35.5,
  "outlet_temp_c": 185.2
}
```

#### 5.4.2 发热片贴附式收集

| 属性   | 说明                          |
| ---- | --------------------------- |
| 原理   | 硅基发热片直接贴附于电池罐体，吸收电池工作时的直接热量 |
| 适用场景 | 电池高倍率充放电时（单体温度>40°C）        |
| 效率   | 接触面热传导效率约70-85%             |
| 控制方式 | 发热片开关控制（ON/OFF）             |

**状态机：**

```
                    ┌─────────────────┐
                    │    待机         │
                    │   STANDBY      │
                    └────────┬────────┘
                             │ 电池温度>40°C + 热量存储未满
                             ▼
              ┌──────────────────────────────┐
              │        热量收集中              │
              │      HEAT_COLLECTING         │
              │   电池罐体热量→发热片→存储    │
              └──────────────┬───────────────┘
                             │ 电池温度<35°C 或 存储已满
                             ▼
                    ┌─────────────────┐
                    │    完成         │
                    │   COMPLETE     │
                    └─────────────────┘
```

| 状态               | 进入条件      | 退出条件      | 关键参数    |
| ---------------- | --------- | --------- | ------- |
| STANDBY          | 初始/温度低    | 电池温度>40°C | 低功耗监测   |
| HEAT\_COLLECTING | 电池高温+存储空间 | 温度下降或存储满  | 发热片工作状态 |
| COMPLETE         | 条件不再满足    | 重新进入检测    | 记录累计收热  |

**数据模型：**

```json
{
  "device_id": "heat_sheet_unit_001",

  "battery_temp_c": 45.2,
  "sheet_temp_c": 52.8,

#### 5.4.3 风冷+压缩机协同散热

| 效率   | 风冷带走热量+压缩机二次转移，综合效率约60-75%        |
| 控制方式 | 风机风速（0-100%）+压缩机联动                |

**状态机：**

```
                    ┌─────────────────┐
                    │    待机         │
                    │   STANDBY      │
                    └────────┬────────┘
                             │ 电池温度>45°C + 有存储空间
                             ▼
              ┌──────────────────────────────┐
              │        风冷+压缩协同           │
              │    FORCED_AIR_COMBO          │
              │   风吹带走热量+压缩机转移     │
              └──────────────┬───────────────┘
                             │ 电池温度<40°C 或 存储已满
                             ▼
                    ┌─────────────────┐
                    │    完成         │
                    │   COMPLETE     │
                    └─────────────────┘
```

| 状态                 | 进入条件    | 退出条件      | 关键参数       |
| ------------------ | ------- | --------- | ---------- |
| STANDBY            | 初始/温度低  | 电池温度>45°C | 待机         |
| FORCED\_AIR\_COMBO | 高温+存储可用 | 温度降低或存储满  | 风机转速、压缩机功率 |

#### 5.4.4 三种方式协同策略

| 工况            | 推荐方式    | 优先级 | 说明         |
| ------------- | ------- | --- | ---------- |
| 电池正常温度15-40°C | 压缩机式    | P1  | 利用充放电余热    |
| 电池高温>40°C     | 发热片贴附   | P1  | 直接接触高效回收   |
| 电池高热>45°C     | 风冷+压缩协同 | P2  | 快速降温+热量转移  |

| 多种高温叠加        | 多方式并行   | P1  | 根据温度阈值自动选择 |

## 7. 异常与边界

### 7.1 异常分类

| 异常等级  | 定义         | 处理方式    | 示例                |
| ----- | ---------- | ------- | ----------------- |
| P0-紧急 | 设备/人身安全威胁  | 强制停机+告警 | 温度>60°C、设备着火      |
| P1-严重 | 影响生产运行     | 切换备份+告警 | 硅基单元故障、通讯中断       |
| P2-一般 | 需要处理但不影响运行 | 记录+计划处理 | 温度偏差2-3°C、个别传感器故障 |
| P3-提示 | 信息性异常      | 记录      | 数据缺失、阈值接近         |

### 7.2 异常处理规则

| 异常ID   | 异常名称    | 检测条件         | 处理动作         | 恢复条件         |
| ------ | ------- | ------------ | ------------ | ------------ |
| EX-001 | 温度超限    | 温度>30°C或<5°C | 强制加热/制冷 + 告警 | 恢复至±5°C内     |
| EX-002 | 硅基单元离线  | 5秒无心跳        | 切换至备用热源 + 告警 | 恢复通讯         |
| EX-003 | 通讯中断    | 连续3次采集失败     | 启用本地控制 + 告警  | 恢复通讯         |
| EX-004 | 存储过热    | 熔融堆温度>300°C  | 停止加热 + 强制散热  | 温度<280°C     |
| EX-005 | 电池SOC异常 | SOC<10%或>95% | 停止充放电 + 告警   | SOC恢复至20-90% |

### 7.3 熔断与回滚机制

```

### A. 特斯拉热泵系统参考模型（提炼）

参考特斯拉Model Y热泵系统（12种制热+3种制冷策略），本平台借鉴以下设计思想：

1. **多模式切换矩阵**：类似八通阀控制，本平台硅基单元支持多工作模式
2. **环境温度+工况联合决策**：根据环境温度和电池状态联合判断温控策略
3. **能量流分配优化**：参考热泵系统的热能分配逻辑，设计电力/热力协同调度
4. **故障模式隔离**：借鉴特斯拉的故障隔离设计，确保单点故障不影响全局
