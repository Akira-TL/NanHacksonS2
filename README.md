# 垃圾电/热能回收管理平台

> 戈壁地区大型电池库温度控制与能源优化系统

## 项目概述

本项目针对戈壁地区丰富的风电资源和极端温差条件下的电池库温控需求，构建了一套完整的**垃圾电/热能回收管理平台**。平台以硅基熔融堆为核心热源，实现弃风电力的热能转化与存储，兼顾电池库温度管理和能源优化。

### 核心特性

- **智能温控**：基于多模式切换的温控策略，维持电池库±2°C精度
- **热能回收**：将弃风电力转化为热能存储，夜间反向供暖
- **能源优化**：整合多源电力，实现波峰波谷的精准调度
- **实时监控**：秒级数据采集，毫秒级告警响应

## 核心状态机

### 硅基单元工作模式

```
待机(STANDBY) ──► 发电(POWER_GEN)
      │                  │
      │                  │ 热能满/电力需求
      ▼                  ▼
   供暖(HEATING) ◄───────┘
```

### 熔融堆热量管理

```
蓄热中(CHARGING) ──► 平衡态(BALANCED) ──► 放热中(DISCHARGING)
  (白天/弃风)           │                    (夜间/寒冷)
       ▲                │                      │
       └────────────────┴──────────────────────┘
```

### 电池库温控

```
保温(INSULATING) ──► 加热(HEATING)
    │15-25°C            │温度<15°C
    │                温度>25°C
    │                或达标
    ▼                   │
制冷(COOLING) ◄────────┘
    │温度>25°C
    │温度15-25°C
    ▼
异常(EXCEPTION)
```

## 热量收集方式

系统支持三种互补的热量收集方式：

| 方式 | 原理 | 适用场景 | 效率 |
|-----|------|---------|------|
| 压缩机式 | 利用压缩机做功，将低温端热量转移至盐融堆 | 电池充放电余热回收 | COP 2.5-4.0 |
| 发热片贴附 | 硅基发热片直接贴附电池罐体，吸收直接热量 | 高倍率充放电时(>40°C) | 70-85% |
| 风冷+压缩协同 | 风扇强制空气流+压缩机辅助散热带走热量 | 电池高温(>45°C) | 60-75% |

热量流向：`电池余热 → 三种收集方式 → 盐融堆存储 → 夜间电池库供暖`

## 核心场景

1. **夜间电池库保温**：环境<5°C时启动供暖，维持15-25°C
2. **弃风电力消纳**：风电富余时切换至发电模式，存储热能
3. **熔融堆反向供暖**：夜间释放存储热能，降低加热成本
